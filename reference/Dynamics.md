# Process Dynamics

Process Dynamics

## Usage

``` r
Dynamics(dynamics)
```

## Arguments

- dynamics:

  `1`, `2`, or `3`. `1` for stable reciprocal regulation, `2` for
  escalating co-activation, and `3` for adaptive recovery.

## See also

Other Data Generation Functions:
[`GenData()`](https://github.com/jeksterslab/manMetaVAR/reference/GenData.md)
