# Simulation Parameters

Simulation Parameters

## Usage

``` r
data(params)
```

## Format

A dataframe with 12 rows and 3 columns:

- taskid:

  Simulation Task ID.

- n:

  Sample size.

- time:

  Number of measurement occassions. If `NA`, measurement occasions vary
  across IDs.

- heterogeneity:

  Transition-parameter heterogeneity multiplier: 0, 1, or 2.
